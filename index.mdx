The RankSpot API gives you programmatic access to AI visibility, competitor research, keyword scoring, backlink analysis, "People Also Ask" mining, and AI-generated content.

**Base URL:** `https://api.rankspot.ai/v1/workspaces/{workspaceId}`

## Authentication

All requests are authenticated with a bearer token. Pass your API key in the `Authorization` header:

```bash
curl -H "Authorization: Bearer $RANKSPOT_API_KEY" \
  https://api.rankspot.ai/v1/workspaces/$RANKSPOT_WORKSPACE_ID/keywords
```

<Steps>
  <Step title="Sign up">
    Create an account at [rankspot.ai](https://www.rankspot.ai).
  </Step>
  <Step title="Generate a key">
    Open **Account settings → API Keys** from the menu under your avatar in the RankSpot dashboard and create a new key.
  </Step>
  <Step title="Pick a workspace">
    ```bash
    export RANKSPOT_API_KEY=your_key_here
    curl -H "Authorization: Bearer $RANKSPOT_API_KEY" https://api.rankspot.ai/v1/workspaces
    export RANKSPOT_WORKSPACE_ID=the_id_you_picked
    ```
  </Step>
</Steps>

## Workspaces and keys

A workspace is one site or brand, and an organization owns one or more of them. You can belong to several organizations: your own, and any that invited you.

An API key is personal. It acts as you and reaches every workspace in every organization you belong to, so each request names one in its path: `/v1/workspaces/{workspaceId}/...`. `GET /v1/workspaces` lists the workspaces your key reaches, each with its organization. If you leave an organization, your key stops reaching its workspaces right away.

Keys created before personal keys reach only the workspace they were made in. They keep working on the older paths without the workspace part (`/v1/keywords`), and get `403` if the path names a different workspace. A personal key on those older paths gets `400` with `workspace-required`.

<Warning>
  Treat your API key like a password. Never commit it to source control or expose it in client-side code.
</Warning>
